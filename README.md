# auscaster's Homebrew tap

Homebrew formulae for auscaster's tools. Install each by its full name, which also trusts it:

```bash
brew install auscaster/tap/ugt          # Get GitHub projects running on your computer, with your AI app
brew install auscaster/tap/scafld       # Deterministic protocol for multi-phase agent work
brew install auscaster/tap/icey         # C++20 media stack and libwebrtc alternative
brew install auscaster/tap/icey-server  # Self-hosted source-to-browser server built on icey
```

`libdatachannel` is here for icey, which needs it.
